Choose one of four views from the top toolbar:

- **Details:** a game list on the left and information about the selected game on the right.
- **Grid:** covers with the status below each image; selecting a game opens the side panel.
- **List:** one row per game with platform, library, playtime, ratings and achievements.
- **Kanban:** one column per status. Dragging a game to another column changes its status.

Switching views closes the side panel while keeping the selected game highlighted.

## Search and filter

Search ignores differences in case and accents. **Filters** opens the panel on the right. You can combine statuses, platforms, playtime, ratings and other criteria.

**Favorites** and **Recent** are independent of status. Recent covers the last 30 days. Genre, developer, publisher and release filters depend on available metadata.

## Statuses and ratings

In **Settings → Statuses**, create, rename, reorder or delete statuses. When deleting a status that has games, choose where to move those games. Automatic rules determine the status for newly added games and for their first session.

From a game's **More** menu:

- Add or remove its favorite mark.
- Use **Rate game…** for a star rating and difficulty in peppers, from half to five.
- Use **Write review…** for your own text.
- Download metadata or show the ROM in Explorer.

In version 0.7.0, the view and filters are not remembered when you reopen the application.
