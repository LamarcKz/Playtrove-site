Playtrove 0.7.0 runs on **64-bit Windows 10 or 11**. Download the files from the [official release](https://github.com/LamarcKz/Playtrove/releases/tag/v0.7.0).

## Choose a format

| File | How to use it | Library location |
| --- | --- | --- |
| `Playtrove-Setup-0.7.0.exe` | Run the installer. It installs for your user without asking for administrator rights and creates shortcuts. | Your Windows user's application data folder. |
| `Playtrove-0.7.0-portable.zip` | Extract the entire ZIP and open `Playtrove.exe`. Keep `portable.txt` next to the executable. | The `data` folder next to the executable. |

You do not need Node.js or programming tools to use the application.

## First launch

Version 0.7.0 is not digitally signed yet. Windows may display **Windows protected your PC**. After checking that the file came from the official release, use **More info → Run anyway** to open it.

Your library starts empty. The application does not include games or emulators. Continue with [Getting started](getting-started.md) to add your games.

See also [data and updates](data-updates.md).
