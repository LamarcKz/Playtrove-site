You can use the local library without creating a Playtrove account. In version 0.7.1, games are imported from ROM folders for the [supported emulators](emulators.md).

## Add your first games

1. Open the **Emulators** tab.
2. Check whether the emulator was found. If necessary, click **Choose…** and select its executable.
3. Under **ROM folders**, click **Add folder** and choose your games folder.
4. Check the suggested emulator and console. For RetroArch, also select an installed core.
5. Use **Add and scan for games**.

Return to **Library** and select a game. **Play** opens its ROM in the configured emulator. The emulator's own setup is still handled in the emulator.

## Change the language

In **Settings → General**, choose **Português (Brasil)** or **English**. The change applies immediately. On first launch, the application follows your Windows language: Portuguese uses Portuguese; other languages use English.

In **Settings**, **General**, **Statuses** and **About** form one group; **Metadata** and **Achievements** form another. The groups use two columns when there is enough width and stack in narrower windows, with headings separating each section. Resizing does not clear fields you are filling in or change saved settings.
