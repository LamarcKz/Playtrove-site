Fullscreen is for using Playtrove on the TV, from the couch, with a controller. It uses the same library as window mode: favorites, statuses, ratings, reviews and achievements are shared.

## Enter and leave

- Click **Fullscreen** in the top bar or press **F11**.
- To return to window mode, use **F11**, the controller's **Create** button or **Menu → Back to window mode**.
- In **Settings → General**, the option to open fullscreen on startup makes Playtrove start in it.

Emulator and ROM folder setup stays in window mode.

## Controller and keyboard

Fullscreen accepts the **DualSense**, over USB or Bluetooth, the keyboard and the mouse. The D-pad or the left stick moves the focus.

| Button | Key | Action |
| --- | --- | --- |
| ✕ | Enter | Confirm |
| ○ | Esc | Back (in the library, returns to window mode) |
| □ | | Search |
| △ | | Add to or remove from favorites |
| L1 / R1 | | Switch collection (All, Recent and Favorites) |
| Options | | Main menu |

The settings let you swap ✕ and ○ on the controller. The **Help** screen, in the main menu, shows the full map.

## Themes

Fullscreen has four themes. Choose one in **Settings → General** or in **Menu → Fullscreen theme**; the change applies immediately and keeps the selected game.

- **Playtrove** (the default): inspired by Playnite's fullscreen mode, with the featured game and one to three rows of covers.
- **Horizon:** a row of games on top, the game's art filling the screen and cards for trophies, playtime and rating.
- **Mosaic:** big covers and round shortcuts for search, filters, achievements, notices, settings and power, in dark gray and red.
- **Panel:** art in the background and big tiles for continue playing, collections, achievements and statistics.

Each theme has its own game details screen, colors and navigation sounds. The themes take their style from game consoles without using their names, logos or sounds.

## What you can do

- **Play:** opens the game in the emulator, as in window mode. While it runs, fullscreen waits and returns to the same game when the emulator closes.
- **Game options:** favorite, status, rating, difficulty, review (with an on-screen keyboard), download metadata and show the ROM in Explorer.
- **Search and filter:** search uses an on-screen keyboard; filters and sorting are the same as in the library and last until you leave fullscreen.
- **Notices:** new achievements, finished metadata downloads and a new app version show up in a corner and in the notices list.
- **Main menu:** back to window mode, theme, settings, update library, random game, help, minimize, exit and the Windows power options (lock, sleep, restart and shut down), always with a confirmation.

## Preferences

In **Settings → General** or in fullscreen's own settings, you set the theme, the theme music and its volume, trailers (library and details, details only or off), the clock, navigation sounds and their volume, and the ✕/○ swap. Fullscreen music playback and volume are separate from window mode.

Music, trailers and the controller pause when the window loses focus or a game is running.

In version 1.0.0, DualSense navigation is still being validated on real hardware; the keyboard and mouse work everywhere.
