A aba **Conquistas** reúne o RetroAchievements e os troféus locais do RPCS3. O progresso também aparece na biblioteca.

## RetroAchievements

1. Abra **Configurações → Conquistas**.
2. Siga o passo a passo para obter sua **Web API Key**.
3. Informe o usuário e a chave, e salve.

O aplicativo valida a conta e passa a consultar o progresso. **Quem desbloqueia as conquistas é o emulador conectado à sua conta**; o Playtrove lê o que foi registrado no site.

A consulta acontece automaticamente a cada cinco minutos com o aplicativo aberto e também após fechar um jogo. Use **Atualizar** para solicitar uma nova consulta. Novos desbloqueios geram avisos.

Os jogos são associados pelo console e pelo nome. Nem todo jogo da biblioteca terá um conjunto correspondente no RetroAchievements.

## Como os troféus são apresentados

O RetroAchievements não fornece as categorias do PlayStation. O Playtrove usa os pontos para apresentar bronze (até 9), prata (10 a 24) e ouro (25 ou mais). A platina indica que todas as conquistas daquele conjunto foram desbloqueadas.

## Troféus do RPCS3

Não é necessária uma conta do RetroAchievements: o Playtrove lê os troféus guardados pelo RPCS3 no computador. Configure o RPCS3 na aba Emuladores.

O RPCS3 instala os troféus na primeira execução do jogo; eles podem não estar disponíveis antes disso. Troféus ocultos ainda não conquistados permanecem escondidos até você usar **Mostrar ocultos**. Os tipos de troféu vêm dos próprios arquivos do RPCS3.

Veja [emuladores](emulators.md) e [solução de problemas](troubleshooting.md).
