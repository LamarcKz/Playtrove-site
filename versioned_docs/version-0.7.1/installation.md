O Playtrove 0.7.1 funciona no **Windows 10 ou 11 de 64 bits**. Use os arquivos da [release oficial](https://github.com/LamarcKz/Playtrove/releases/tag/v0.7.1).

## Escolher o formato

| Arquivo | Como usar | Onde fica a biblioteca |
| --- | --- | --- |
| `Playtrove-Setup-0.7.1.exe` | Execute o instalador. Ele instala para seu usuário, sem pedir administrador, e cria atalhos. | Na pasta de dados do usuário do Windows. |
| `Playtrove-0.7.1-portable.zip` | Extraia o ZIP inteiro e abra `Playtrove.exe`. Mantenha `portable.txt` ao lado do executável. | Na pasta `data`, ao lado do executável. |

Não é preciso instalar Node.js ou ferramentas de programação para usar o aplicativo.

## Primeira abertura

A versão 0.7.1 ainda não tem assinatura digital. O Windows pode mostrar **O Windows protegeu o computador**. Depois de conferir que o arquivo veio da release oficial, use **Mais informações → Executar assim mesmo** para abri-lo.

A biblioteca começa vazia. O aplicativo não inclui jogos nem emuladores. Continue em [Primeiros passos](getting-started.md) para adicionar seus jogos.

Veja também [dados e atualizações](data-updates.md).
